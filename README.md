# DC 美食大空间（公共库）

DC 美食助手模组的**公共云端内容库**，所有玩家免账号使用，模组会自动拉取并合并。

## 结构

| 目录 | 内容 | 更新方式 |
| --- | --- | --- |
| `foods/` | 公共食材元素值表（社区实测） | 管理员合入投稿 |
| `recipes/` | 公共精选食谱（含工序） | 管理员合入投稿 |
| `sounds/` | 公共音效库（含 manifest.json 清单） | 管理员合入投稿 |
| `pending/` | 玩家投稿队列（分享码） | 玩家提交，管理员定期处理 |

## 使用

- 模组设置 → 公共大空间 → 开启「自动同步公共库」
- 无需任何账号，启动 / 手动刷新即可更新
- 个人云端数据仍走你自己的 GitHub 私有仓库；没有 GitHub 也能通过分享码互相分享

## 投稿（如何把内容放进公共库）

1. 模组内生成分享码（Gist，永久有效）
2. 把分享码发到公共库 `pending/`（或交给管理员）
3. 管理员审核后合入对应目录，全服玩家即可用

> 公共库只读开放，写入由管理员完成，玩家不需要也不应该获取任何管理员令牌。
